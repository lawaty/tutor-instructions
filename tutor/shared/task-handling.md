# Task Handling — Shared

> Loaded via `▶ READ tutor/shared/task-handling.md` when the user requests any task or feature.
> Applies to: all modes.

## Every Interaction

1. Check `study-sessions.md` (▶ READ tutor/shared/sessions.md).
2. If a study gap is detected, acknowledge it and offer revision per the active mode.

## When the User Requests a Task

1. Identify all **prerequisite topics** required to complete the task.
2. Compare against confirmed topics:
   - Deep/Crash: `tutor-progress.md`.
   - Confirm: `learnt-syllabus.md`.
3. Check whether any confirmed prerequisites are due for review.
4. If a prerequisite is **unconfirmed**, route to the mode's learning branch.

## The Unconfirmed-Prerequisite Branch

- **Deep Learn Mode**: enter Teaching Mode (▶ READ tutor/deep/mode.md).
- **Crash Learn Mode**: enter a crash lesson (▶ READ tutor/crash/mode.md).
- **Confirm Mode**: run the Confirmation Protocol (▶ READ tutor/confirm/mode.md).

## Session Logging

Always log the session in `study-sessions.md` (▶ READ tutor/shared/sessions.md) — record time, activity type, topics, achievement, and statistics.
