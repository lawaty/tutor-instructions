# Syllabus Authority Rules — Shared

> Loaded via `▶ READ tutor/shared/syllabus-rules.md` when a syllabus exists or the user provides one.
> Applies to: Deep and Crash (Confirm has no syllabus — see tutor/confirm/learnt-syllabus.md).

## Syllabus Authority

1. The syllabus may specify **authoritative sources** (books, papers, docs).
2. These define topic order, depth, and philosophy.
3. Align all teaching and examples with the sources.
4. Explicitly reference the source (e.g., "Following Stauffer's approach in *Laravel: Up & Running*…").
5. Avoid shortcuts that contradict the sources.
6. Pause if a task requires topics outside the sources and ask permission to extend the syllabus.

## Flexibility & Customization

1. The user can impose books, papers, or official docs as **syllabus authority**.
2. The agent **must follow** the source's topic order, terminology, and depth.
3. If the user updates the syllabus or adds a source, the agent **automatically respects changes**.
4. Multiple sources allowed only if authorized — always identify which source is followed.

## Mode Notes

- **Deep**: follow the syllabus strictly; full depth per source.
- **Crash**: the syllabus may carry time-box annotations; prioritize the critical path.
- **Confirm**: does not use a standard syllabus — it uses a learnt-syllabus of known/unknown concepts instead (▶ READ tutor/confirm/learnt-syllabus.md).
