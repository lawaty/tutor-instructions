## Crash Lesson Template

Keep each lesson doc short (40–80 lines vs. Deep's 200–500):

```markdown
# [Topic Name] — Crash
**Source**: [Doc/ref] (link)
**Time**: [30–120 min]
**Prerequisite**: [List]

## The One Thing
[The single essential idea, 2–3 sentences]

## Minimal Demo
[One short, working, copy-run-modify example]

## Steps
1. [Actionable step]
2. [Actionable step]
3. [Actionable step]

## Gotchas
- [Only the most common traps]

## Go Deeper
[One link/section for optional depth]
```

## Minimal-Theory Rules

- Explain only what the current task requires.
- Explicitly name what was skipped.
- Provide one "go deeper" link line for optional exploration.
- No long book quotes, no extensive cross-referencing unless immediately useful.

## Demo Standards

One minimal, runnable example that:
- Runs without extra setup.
- Demonstrates the exact concept needed for the task.
- Is commented in 1–2 lines max.
