## Revision Session Structure

Create a revision document at `.ai/revisions/revision-[date]-[topic-area].md`:

```markdown
# Revision Session: [Topic Area]

**Date**: [YYYY-MM-DD]
**Topics Covered**: [Topic 1], [Topic 2], ...
**Last Studied**: [...]
**Estimated Duration**: [20-45] minutes

## Why This Revision?
[Study gap, review schedule, milestone, etc.]

## Quick Refresher Summary
### [Topic 1]
**Core Concept**: [One-sentence essence]
**Key Points to Remember**: [Essential points]
**Common Pattern**: [Code]
**Connection to Other Topics**: [Builds on / Used with / Enables]

## Hands-On Revision Exercises
### Exercise 1: Pure Recall Challenge
**Task**: [Coding task requiring Topic 1]
**Constraints**: No references, no autocomplete, 10-min limit
**Success Criteria**: [Code runs, correct understanding, proper syntax]

### Exercise 2: Topic Integration
**Scenario**: [Realistic scenario requiring multiple topics]

### Exercise 3: Explain and Enhance
**Given Code**: [Working but basic code]
**Tasks**: Explain (comments), critique (2-3 improvements), enhance

## Reflection Questions
1. What surprised you during this revision?
2. Which topic felt rusty? Which felt solid?
3. What connections are now clearer?
4. What would you do differently in a real project?

## Revision Completion
1. Tell me you've completed the exercises
2. I'll review and give feedback
3. We'll update progress with new review dates
```

## Revision Session Rules

1. Keep it focused — 2–5 related topics (20–45 min).
2. Summarize, don't re-teach.
3. Emphasize connections.
4. Active recall first — exercises before reviewing references.
5. Real application, not toy examples.
6. Immediate feedback.
7. Update `Last Reviewed` / `Next Review Due` in progress.
8. Log the session.

## Revision Exercise Types

Rotate for different cognitive skills:
1. Pure Recall — from memory, no references.
2. Integration — combine topics in one task.
3. Code Reading — explain and improve given code.
4. Debug Hunt — find and fix bugs.
5. Edge Cases — unusual scenarios.
6. Pattern Recognition — when to use which approach.
7. Quick Fire — 5 rapid mini-tasks, 2 min each.
