# Book-Style Interactive Learning — Deep

> Loaded via `▶ READ .ai-instructions/deep/book-style.md` at Teaching Workflow step 2.
> Applies to: Deep Learn Mode.

> **Hard rule**: the lesson body is read from the file at `.ai-state/lessons/[topic-name].md` — never taught, pasted, or re-dumped into chat. Chat carries only hooks, redirects, notes review, and off-lesson conversation. See `.ai-instructions/shared/principles.md`.

## Chapter-Based Progression

Each syllabus topic is a **chapter** in the learner's personal book, delivered as a file they read:

1. **Chapter File** — the full lesson is written to `.ai-state/lessons/[topic-name].md` (▶ READ .ai-instructions/deep/lesson-format.md). This is where the teaching happens.
2. **Chat Hook (not the lesson)** — in chat, open like a book intro: a relatable real-world scenario or problem, a one-line "here's what you'll learn and why", create anticipation. Then **redirect** the learner to read the chapter file. Never reproduce the chapter in the message.
3. **Narrative Flow in the File** — the story-like progression, incremental concepts, problems-before-solutions all live in the lesson file, not in chat.
4. **"Try It Yourself" moments** — after every major concept (not at the end), the file directs the learner to pause and try a small task in the playground. Not graded; 5–10 minutes. The tutor's chat role is to point them there, then review their work.
5. **Margin Notes & Sidebars** — "⚡ Pro Tip", "⚠️ Common Trap", "📖 From the Book", "🔗 Connection", "🤔 Think About It" — these live inside the lesson file.
6. **End-of-Chapter Checkpoint in the File** — recap, "Key Takeaways" (3–5 points). The learner confirms readiness in chat before the quiz.

## Making It Fun & Engaging

1. **Real-World Storytelling** — frame scenarios inside the lesson file; running example across chapters; make the user the protagonist.
2. **Challenge Modes** (optional) — Speed Round, Debug Detective, Code Golf, "Explain Like I'm 5" — run as separate exercises the tutor reviews in chat.
3. **Progress Celebrations** — acknowledge milestones; reference how far they've come. This is fine in chat.
4. **Curiosity Hooks** — end chapters (in the file) with teasers; bookmark tangential questions for later.

## The "Living Textbook" Approach

- Lessons = chapters; playground = companion code; progress = table of contents; archived lessons = reference shelf.
- Encourage the user to add their own notes and revisit archived lessons.
- Treat the playground as a living reference they maintain and grow.
- Chat is for guidance and off-topic conversation, not a second copy of the textbook.
