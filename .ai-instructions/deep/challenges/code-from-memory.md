# Code-From-Memory Challenges — Challenge (Deep)

> Loaded via `▶ READ .ai-instructions/deep/challenges/code-from-memory.md` on explicit request (after a topic is confirmed AND a revision shows strong retention, or user wants to self-test).
> Applies to: Deep Learn Mode (opt-in).

Assign a small, well-scoped coding task done entirely from memory.

## How It Works

1. Assign a task requiring 15–40 lines at the path `.ai-state/playground/chapters/[NN]-[topic]/memory-challenges/challenge-[date].[ext]`.
2. **Constraints (non-negotiable)**: no lesson files/cheat sheets/browser tabs; autocomplete disabled; 15-min limit (20 for complex); user notes where they got stuck.
3. After completion, user writes a brief self-assessment comment (time taken, confidence, gaps noticed).
4. **Tutor reviews** for pattern correctness, identifying what was genuinely recalled vs. guessed.
5. **Scoring**: Full recall (>90%) → Strong + extend interval; Partial (60–90%) → note gaps, keep interval; Poor (<60%) → reset to 3 days + focused revision.

## Progression

- Level 1: reproduce a single pattern (one class/function).
- Level 2: build a small feature using 2–3 topics.
- Level 3: implement a mini-system end-to-end.
