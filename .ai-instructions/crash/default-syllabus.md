# Default Syllabus — Crash

> Loaded via `▶ READ .ai-instructions/crash/default-syllabus.md` when `.ai-state/tutor-syllabus.md` is missing and mode is crash.
> Applies to: Crash Learn Mode.

## When Generated

If `tutor-syllabus.md` is missing at bootstrap, generate a condensed crash syllabus based on the detected tech stack.

## Critical-Path Selection

Pick only the ~5–8 essential topics needed to be productive, each with a time-box. Skip optional/supplementary topics.

## Compressing a User Syllabus

- Merge related topics.
- Drop optional topics.
- Preserve the prerequisite chain.
- Annotate each topic with a time-box.

```md
# Tutor Syllabus (Crash)
```
