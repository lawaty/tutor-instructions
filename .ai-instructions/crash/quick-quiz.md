## Quick-Quiz Format

Still **file-based** (maintain the file discipline), but streamlined:

```markdown
# Quick Quiz: [Topic Name]

**Topic**: [Topic Name]
**Attempt**: 1 of 2
**Date**: [Date]

## Part 1: Recall (1–3 questions)
### Q1: [Question]
**Your Answer:**
<!-- Write here -->

## Part 2: Small Practical Task (1)
### Task: [Minimal, well-scoped task]
**File**: <!-- path to implementation -->
**Explain in one sentence**: <!-- how it works -->
```

## Passing Criteria

- Working code + at least 1 correct explanation.
- Simple **pass / pass-with-gaps / fail** — no numeric rubric.

## Retry Rules

- 1 retry allowed.
- If still failing, **confirm-with-gaps** and add to the review list.

## Purpose

Verify comprehension fast without heavy grading. The review list handles long-term retention.
